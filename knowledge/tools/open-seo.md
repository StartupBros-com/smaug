OpenSEO is an open source, pay-as-you-go alternative to Semrush and Ahrefs, built to be used by you and your AI agent. It exposes an MCP server and prebuilt agent skills so Claude Code, Codex, ChatGPT and similar agents can run SEO workflows directly. SEO data comes from your own DataForSEO API key. The author notes the whole stack runs on Cloudflare (Durable Objects, KV, R2, D1, Agents) plus Planetscale for the hosted product, which cost about $5/month until recently.

## Key Features

- Keyword research, rank tracking, competitor insights, backlinks, site audits, AI visibility
- MCP server plus Agent Skills for Claude Code, OpenClaw, Hermes, Codex, ChatGPT
- Self-host via Docker (Coolify, Portainer, Dokploy) or one-command Cloudflare deploy (works on the free plan)
- No subscription: bring your own DataForSEO key; hosted version is $10/month
- Fork and vibe code your own custom tool
