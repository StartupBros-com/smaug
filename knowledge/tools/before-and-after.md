before-and-after is an agent skill from Vercel Labs that teaches coding agents to put visual proof in every pull request. It captures before and after screenshots or recordings and attaches them to GitHub PR descriptions, so reviewers can see a change instead of reading about it. The v0.1.0 update adds video support, uploads directly to GitHub, and gets past preview deployment protection.

## Key Features

- Install with `npx skills add vercel-labs/before-and-after#main`
- Before and after screenshots and video recordings attached to PR descriptions
- Access to protected preview deployments, so captures work on gated previews
- Formats each capture for GitHub
- Pairs with the GitHub CLI `--attach` flag (announced 2026-09-01) for uploading local images or video into issues, PRs, and comments
