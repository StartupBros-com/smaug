`how` is a Cursor skill for explaining unfamiliar codebases at an onboarding-friendly architectural level. It routes simple questions to one agent and decomposes broader investigations into parallel explorations, then can add a multi-model critique to identify architectural concerns before implementation work begins.

## Key Features

- Produces structured overviews covering concepts, flows, relevant files, and gotchas.
- Chooses between straightforward explanation and a deeper critique workflow.
- Splits cross-cutting questions into parallel exploration angles and synthesizes their results.
- Offers prompts for tracing features, user flows, middleware, and subsystem design.
