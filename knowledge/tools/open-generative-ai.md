Open-Generative-AI is an MIT-licensed JavaScript project that presents a unified interface for image and video generation workflows. The repository positions it as an open alternative to commercial creative-AI platforms, covering text-to-image, image-to-image, text-to-video, image-to-video, lip-sync, and cinema-oriented controls.

The project’s README also links to MuAPI-hosted and white-label offerings. Its open-source license and interface are distinct from the availability, local execution, and cost of the model backends, which should be verified for a specific deployment.

## Key Features

- Combines multiple generative-media workflows in a single studio-style interface.
- Supports image and video creation modes, including text- and image-conditioned generation.
- Is distributed under the MIT License and implemented in JavaScript.
- Documents related tools and integrations for generative-media applications.
- Promotes optional hosted and white-label paths alongside the repository.
