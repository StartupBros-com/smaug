Public archive of a six-week course (Aug-Oct 2026) teaching marketers to use Claude Code and Codex. It collects session recordings, verbatim transcripts for the six main sessions, office hours and guest sessions, slide decks, and supporting resources, totalling over 18 hours of material. It is meant to be dropped into Claude Code so the agent can draw on the course methods; Parker's marketing MCP (Meta ads, competitor ads, reviews, TikTok, Reddit data) supplies the data side.

## Key Features

- Week 0 setup: Claude Code, Claude chat vs. Claude Code, GitHub, MCPs
- Weeks 1-6: fundamentals, skills and routines, shared brain and multiplayer AI, static ads in code, video workflows and creator operations, landing pages
- Verbatim transcripts, archived slide PDFs, and links to recordings and Notion learner pages
