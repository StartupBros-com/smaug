Open-source (MIT) agent skill by Taras Shynkarenko that adds a "Make us preferred on Google" button to any website, in the footer and under every article. It works with Claude Code, Codex and Cursor. Bookmarked after Glenn Gabe noted Google now emails site owners how many people added them as Preferred Sources in Top Stories.

## Key Features

- Covers placement, wording, framework-agnostic code and tests
- Installable as a SKILL.md; source on GitHub (TarasShyn/skills)
