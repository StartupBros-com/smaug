12-Factor Agents is Dex Horthy's (HumanLayer) set of principles for building LLM-powered software reliable enough for production customers, modeled on the 12-factor app. Its thesis is that good agents are mostly deterministic software with LLM steps placed at the right points, not "prompt plus a bag of tools looped until done".

## Key Features

- Twelve factors covering topics such as owning your context window (factor 3), tool calls as structured output, and small focused agents
- Written from conversations with many production AI founders who mostly roll their own stack instead of using frameworks
- Companion conference talk and YouTube deep dives
- Code under Apache 2.0, content under CC BY-SA 4.0
