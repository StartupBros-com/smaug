Weatherbot is a GitHub project presented as the implementation baseline for an automated Polymarket weather-market trader. In the linked guide, it is configured to compare weather forecasts across multiple cities, estimate expected value, and size positions with a Kelly-criterion-based approach while an external Hermes Agent manages setup and continuous operation. The repository metadata supplied with the bookmark contains no README or description, so the exact implementation and current maintenance status should be verified in the source before use.

## Key Features

- Intended as a Python-based foundation for scanning and trading Polymarket weather contracts.
- Referenced with forecast inputs, expected-value filtering, and configurable per-trade risk limits.
- Designed in the accompanying guide to run continuously and to be operated by a self-hosted agent.
- Requires careful review of wallet, secret, API, and live-trading safeguards before any deployment.
