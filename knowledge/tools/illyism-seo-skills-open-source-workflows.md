An open-source collection of SKILL.md workflows (the README now lists 30, the tweet mentions 12) that turn coding agents such as Claude Code, Cursor and Codex into SEO operators. Each skill is built to end in a concrete output (merged diffs, rewritten titles, redirect maps, comparison pages) rather than an audit PDF. About 1.2K stars.

## Key Features

- seo-autopilot: daily repo SEO checks, keyword map, comparison pages and AI answer tracking with persistent state
- blog-refresher: SERP gap analysis to push pages ranking #8-#20 toward the top 3
- seo-title-optimization: CTR-driven title and H1 rewrites from Search Console data
- customer-journey: maps the prompts buyers type into Google and ChatGPT
- linkdr: plans and orders in-content DR 30-60+ backlinks from the terminal
- Also covers proof KBs, blitz-seo (focus on one money page), GEO/AEO citation tracking, Ahrefs and DataForSEO MCP workflows
- Install with `npx skills add Illyism/seo-skills` (or `--skill seo-autopilot` for one)
