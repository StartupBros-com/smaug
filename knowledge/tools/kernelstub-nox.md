NOX is a modular attack-surface management and vulnerability-scanning framework written in Go. It targets security researchers and penetration testers who need an extensible platform for reconnaissance and active testing.

## Key Features

- 299 built-in modules for security discovery and testing
- OSINT, subdomain enumeration, DNS reconnaissance, and port scanning
- Web fingerprinting and active testing across web applications and APIs
- Coverage for cloud environments, authentication, authorization, client-side behavior, and business logic
- Go implementation designed for fast, modular offensive-security workflows
