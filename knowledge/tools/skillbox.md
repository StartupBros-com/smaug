Self-hosted, versioned skills library for AI agents, open-sourced under MIT by Kitze. It centralizes scattered markdown skills in one place and serves them to agents through MCP with scoped clients. An optional Jev integration lets a small classifier read the agent's query and return the relevant skills immediately, instead of the agent spending many turns searching for the right one.

## Key Features

- Self-hosted and versioned skills storage for AI agents
- MCP server access with scoped clients
- Optional Jev recommendations to pick relevant skills from a query
- README is written for agents: ask your agent to set it up and port your existing markdown skills
