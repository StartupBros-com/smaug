Fieldwatch is a receive-only Wi-Fi and Bluetooth LE observer for Android (Kotlin, MIT licensed, ~4.8k stars). It passively listens for nearby radios and matches them against a signature library so the user can see what is operating around them. There is no dongle, account, backend server or ads, and it works offline. It is sideloaded from GitHub rather than the Play Store. Bookmarked via a tweet saying it alerts when it detects a likely police-vehicle signature.

## Key Features

- Passive scanning of Wi-Fi access points and Bluetooth LE devices, with a filtering engine and customizable views
- Signature library (329 signatures per the 1.2.0 announcement) covering things like smart glasses, plate-reader cameras, body cams, public safety vehicles and drones; users can add their own
- Warnings for Bluetooth pairing floods, possible GPS interference, and trusted-network anomalies
- Drone Remote ID perimeter and swarm alerts, map views and report generation (per the 1.2.0 announcement)
- Imports and exports signatures using Radio Signature Interchange (RSI)
