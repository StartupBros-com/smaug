This repository collects Clawdbot skills for agentic coding work, covering the Agentic Coding Flywheel Setup toolchain, workflow methods, and cloud or development CLIs. The skills are Markdown operating guides that give a multi-surface assistant enough command syntax, examples, and practices to use tools across messaging, web, voice, and local environments.

The bookmark documents using the collection to extend a personal Clawdbot installation with tools such as Cloudflare Wrangler, Vercel CLI, and the author’s own agent-flywheel utilities. It also recommends the separate ACIP prompt layer when agents receive untrusted external messages.

## Key Features

- Supplies skills for session search, task-graph triage, agent coordination, destructive-command controls, and repository maintenance.
- Adds workflow guides for planning, multi-agent implementation, skill authoring, and interface polish.
- Provides integrations for development and cloud tooling while calling out prompt-injection exposure on external input surfaces.
