Loopy is the companion skill for Forward Future's Loop Library, a public catalog of reusable AI-agent workflows. A loop is a bounded playbook that specifies a goal, an evidence-based check, the next action when a check fails, and a stopping or escalation condition—making iterative agent work more repeatable than a one-shot prompt.

The new Discover, or "Lazy Loops," capability examines a codebase and previous chat threads to find recurring work that could be formalized as a loop. It can then propose a workflow rather than requiring the user to identify and design every repeated process manually.

## Key Features

- Searches codebases and agent chat threads for repeatable tasks suitable for a bounded workflow.
- Recommends, audits, repairs, adapts, or creates loops using the live Loop Library catalog.
- Defines each loop around an explicit objective, verification method, follow-up action, and stopping condition.
- Runs loops in limited passes and returns a receipt describing actions, evidence, outcome, and stopping reason.
- Supports saving project-specific loops to `LOOPS.md` while requiring approval before publication or externally consequential actions.
