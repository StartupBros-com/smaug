Beads Viewer (`bv`) is a graph-aware terminal interface for projects that use the Beads issue tracker. It turns issue dependencies into navigable views and computed analysis, helping developers and coding agents identify priorities, bottlenecks, cycles, and the critical path without leaving the terminal.

The tool can also generate static project sites with `bv --pages`. The bookmark demonstrates this capability through FrankenSim's published graph of 238 Beads tasks, showing a shareable representation of a project's plans and dependencies.

## Key Features

- Keyboard-driven TUI for browsing Beads issues and their details.
- Dependency-DAG visualization with PageRank, critical-path, and cycle analysis.
- Kanban and graph views for tracking workflow and dependency structure.
- Robot-mode JSON and TOON output for coding-agent workflows.
- Static-site generation via `bv --pages` for publishing project graphs.
