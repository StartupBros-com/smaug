A cap table modeling tool built by 1984 (1984.vc) and shared by Mark Percival (@mdp). The pitch from the tweet is that early founders often do not understand their cap table or how different investments dilute them. AI is a good way to model it, but only if it has proper tools to compute the numbers correctly. This repo is meant to be that tool. The GitHub API returned no README or description when this was captured, so details beyond the tweet are not verified.

## Key Features

- Built to be used alongside AI for cap table modeling (per the tweet)
- Aimed at early founders who want to see how financing rounds affect ownership
