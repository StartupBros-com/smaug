A curated, high-signal index of autonomous improvement loops inspired by Karpathy’s `autoresearch`. It organizes reusable agent systems that repeatedly propose a change, measure an outcome, and retain or revert the change, making the pattern easier to adapt beyond model-training experiments.

The collection includes general-purpose descendants, research-agent systems, platform and hardware ports, domain-specific applications, evaluation resources, and explanatory writeups. Its listed examples range from Apple Silicon, Windows RTX, browser WebGPU, multi-GPU, and hosted-notebook implementations to applications in trading, genealogy research, and software development.

## Key Features

- Catalogs autonomous optimization systems around explicit metrics and iterative experiments.
- Separates general-purpose agent loops from research systems, hardware ports, and domain adaptations.
- Links implementations for Claude Code, Codex, Gemini, and local agent workflows.
- Includes benchmarking, evaluation, and case-study resources alongside repositories.
