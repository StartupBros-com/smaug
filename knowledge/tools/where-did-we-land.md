An agent skill (/where-did-we-land) that turns a meeting transcript into one self-contained HTML page showing where every thread landed, backed by the quote that proves it. Bookmarked as a better-than-Granola way to clean up messy meetings.

## Key Features

- Topic timeline, ledger of thread outcomes with proof quotes, open loops, commitments, stances, and airtime.
- Plain HTML output: no hosting, build step, or dependencies.
- Installs via `npx skills add gnurio/where-did-we-land` or as a Claude Code plugin.
