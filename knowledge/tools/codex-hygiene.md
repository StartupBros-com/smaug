Codex Hygiene is a read-only Codex skill for measuring and reviewing local context and tool usage before recommending scoped, reversible configuration changes. It keeps prompts, responses, tool output, full paths, environment values, and other sensitive local data out of its reports while distinguishing observed evidence from interpretation and uncertainty.

## Key Features

- Measures recent tool-list and per-thread token telemetry, or produces reviews across a selected 1–90 day window.
- Audits the current Codex profile for installed plugins, MCP state, Apps availability, and project configuration counts.
- Enriches activity reviews with timing, tool-output weight, verification commands, compactions, and skill reads.
- Suggests reversible hygiene improvements only after collecting evidence and stating coverage limits.
