Newsjack is an open-source collection of skills that turns an AI coding agent into a PR workflow assistant. It combines news monitoring, relevance and freshness checks, media-angle development, journalist fit assessment, fact checking, and other communications tasks so teams can identify and respond to credible opportunities without blanket outreach.

The repository supports multiple agent environments, including Claude Code and Codex. Its skills are organized around detecting relevant news, producing PR materials, developing strategy, and improving AI visibility; some workflows also support local monitoring and coverage tracking.

## Key Features

- Detects and triages news opportunities against a company's topics, competitors, evidence, and standing.
- Generates angles, headlines, reactive comments, media lists, and fact-checked outreach materials.
- Includes journalist-fit and same-outlet ranking steps to encourage targeted pitches over contact-list spraying.
- Provides PR strategy and calendar workflows alongside AI-visibility analysis tools.
