`/teach` is a selectable skill from Matt Pocock's composable agent-skill collection. It is intended to make an agent teach a chosen subject interactively, with the launch post naming Rubik's Cube, vocal harmonies, and software fundamentals as examples. The parent repository frames its skills as small, adaptable workflows for real engineering rather than an all-encompassing process framework.

## Install

```bash
npx skills add mattpocock/skills --skill teach
```
