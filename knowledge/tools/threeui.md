ThreeUI is Meng To's open-source catalog of three.js components and landing page sections, with live interactive previews on threeui.com. The Community edition is free and login-free: procedural 3D hero sections, icons, and motion designs whose prompt or source can be handed to a coding agent and then adjusted for theme, lighting, motion, or layout. @trashh_dev bookmarked it (quoting the launch post) to upgrade their personal site.

## Key Features

- 50 Community parent components and 160+ free variants/routes, with full source and assets
- Variant picker, controls, and source tabs on each component page
- Installable as a React package: `npm install @designcodeio/threeui`
- Paid Pro tier adds 50+ components, MCP, and skills
- Repo funded by README and website sponsorships
