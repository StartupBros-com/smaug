Claude Code / Codex / Pi skill that emits editorial-quality diagrams as self-contained HTML + SVG — no Figma, no build step, no generic rounded-box Mermaid slop. Built by Cathryn Lavery (littlemight.com / BestSelf.co) after agents kept returning diagrams that did not match the rest of the site. One skill, 28 visual types, brand colors pulled from a URL in about a minute. ~23k GitHub stars at capture.

## Key Features

- 28 diagram types shipping in three static variants (minimal light, minimal dark, full-editorial): architecture, flowchart, sequence, state machine, ER, timeline, swimlane, quadrant, nested, tree, org chart, Venn, layer stack, pyramid/funnel, consultant 2×2, radar, loop/flywheel, IT current-state, plus later semantic system patterns
- Semantic patterns (queue, policy trace, trust boundary) reuse the nearest type instead of exploding the catalog
- Static HTML is the default; optional accessible motion for ordered explanations
- Redraws existing draw.io or Mermaid sources at a chosen format, size, and detail level
- Accent color reserved for the 1–2 things the reader should see first; target density 4/10; "the highest-quality move is usually deletion"
