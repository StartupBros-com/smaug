A collection of Claude Code skills from HumanLayer, installable individually with `npx skills add humanlayer/skills --skill NAME`. Matt Pocock called the `show-me` skill phenomenal for making PR descriptions easy to read, describing it as a toolbox of "nice ways to look at code".

## Key Features

- **show-me**: explains the current topic with concise diagrams, code-shape sketches, and focused HTML artifacts
- **visual-pr**: creates or updates a pull request with a concise visual outline to help reviewers
- **rpi**: research, design discussion, PRD/TDD or technical design, then implementation from local documents, with each phase in a fresh session
- **improve-claude-md**: rewrites CLAUDE.md using `<important if>` blocks to improve instruction adherence
- **narrow-react-prop-types**: narrows React prop types to live code paths rather than Storybook/test/mock-only states
- **build-iterated-agentic-loop** and **design-control-loop**: scaffold iterated coding-agent GitHub Actions workflows and sensor/controller/actuator control loops
