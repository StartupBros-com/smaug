An open-source curriculum for learning how to design scalable software systems, from network and data fundamentals through distributed-system patterns and realistic product exercises. It is intended both as a structured introduction to architecture and as preparation for system-design interviews.

## Key Features

- Covers networking, availability, caching, databases, replication, sharding, and consistency models.
- Explains architectural patterns including microservices, event-driven systems, APIs, message queues, and service discovery.
- Applies the material to system-design exercises such as URL shorteners, WhatsApp, Twitter, Netflix, and Uber.
