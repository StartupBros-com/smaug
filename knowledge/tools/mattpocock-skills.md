# mattpocock/skills

A collection of composable agent skills for engineering work, published by Matt Pocock. The highlighted `grill-me` skill is intended to create alignment before implementation by having the agent ask detailed questions about the intended change.

## Why it is useful

The repository frames agent failure as a communication and shared-context problem rather than only a model-capability problem. Its skills are deliberately small and adaptable, offering an alternative to workflow frameworks that own the entire development process.

## Highlighted practice

Use a structured questioning phase to establish the repository context, desired behavior, and constraints, then retain that shared understanding in project working documents. This helps prevent rushed, poorly scoped feature work and makes later implementation decisions traceable.
