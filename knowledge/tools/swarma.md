swarma is a work-in-progress project for running agent swarms that execute growth experiments, ingest the resulting knowledge, and accumulate validated patterns into a reusable playbook. The project applies an AutoResearch-style feedback loop to growth work, with Hermes proposed as the orchestrator and Honcho memory as the shared context layer.

## Key Features

- Coordinates multiple agents around repeated growth experiments rather than one-off outputs.
- Captures outcomes as knowledge and promotes validated tactics into a compounding playbook.
- Connects an AutoResearch loop with QMD, Hermes orchestration, and Honcho memory.
- Extends the LLM-maintained knowledge-base model into an operational learning loop for growth.
