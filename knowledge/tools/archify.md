`archify` is an agent skill that turns an idea, plan, or codebase into a self-contained interactive HTML diagram. It covers architecture, workflow, sequence, data-flow, and lifecycle diagrams, with motion and crisp export.

It works with Claude Code, Codex, and other coding agents: you describe what you want to understand or share, and the agent generates an explorable, customizable visual. It was trending on GitHub at the time of the bookmark (about 25k stars in the tweet, far more by the API snapshot).

## Key Features

- Verifiable architecture, sequence, and data-flow diagrams as single-file HTML
- Animated, interactive output with export
- Skill packaging for Claude Code, Codex, OpenCode, and similar agents
