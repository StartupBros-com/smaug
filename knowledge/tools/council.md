An agent skill from Kitze that makes your coding agent convene the other agent CLIs installed on your machine and deliberate with them for a set number of turns before handing back a plan. Kitze recommends using it to have different models (e.g. Astra and Fable) argue about how sloppy a codebase is.

## Key Features

- Agent skill that orchestrates multiple agent CLIs on the same machine
- Configurable number of deliberation turns before a plan is produced
- Useful for codebase quality critiques and cross-model planning
