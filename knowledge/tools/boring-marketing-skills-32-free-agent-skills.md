boring-marketing-skills is James Dickerson's (The Boring Marketer) MIT-licensed pack of 32 free marketing skills for AI agents such as Claude Code, Codex and Cursor. The skills were built from real campaigns and each works without a paid tool. Greg Isenberg bookmarked it as the example of the "open-source your SaaS workflows as skills" playbook.

## Key Features

- Install with `npx skills add boringmarketer/boring-marketing-skills`, or as a Claude Code plugin via `/plugin marketplace add`
- `/start-here` reads a business's site and reviews, writes shared brand files, and routes to the next skill (about 3 minutes on first run)
- Skills are grouped by stage: start here, get found (local SEO, AI search, site audit, programmatic SEO), get chosen (reviews, landing pages, copy, lead magnets), get the call (paid ads, tracking, speed-to-lead), bring them back (email, newsletter), win clients, market yourself
- Every skill reads the same brand files, and each skill can keep a separate folder per client
- Includes a deep pack for local businesses and the people who market to them
