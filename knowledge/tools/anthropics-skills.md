Anthropic’s public repository of Agent Skills: self-contained instruction, script, and resource folders that Claude can load dynamically for specialized workflows. The bookmarked `discernment-nudge` skill is notable for explicitly defining when an agent should not surface a self-check, making restraint a first-class part of agent behavior design.

## Key Features

- Open examples and reference implementations for reusable Agent Skills across creative, technical, enterprise, and document workflows.
- Each skill is packaged as a folder centered on a `SKILL.md` instruction file, with optional scripts and supporting resources.
- Includes the `discernment-nudge` skill, highlighted for its careful trigger logic around when Claude should second-guess itself in front of the user.
