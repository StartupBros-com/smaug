Paper2Code is a Claude Code skill for translating an arXiv paper into a working implementation while preserving an audit trail from each code line back to the paper section that motivated it. Rather than silently choosing details the paper omits, the skill is designed to flag those gaps for explicit decisions.

## Key Features

- **Paper-to-Code Traceability**: Connects implementation lines to their originating paper sections
- **Assumption Disclosure**: Identifies implementation details that are not specified by the source paper
- **Claude Code Integration**: Packages the workflow as a reusable skill for research implementations
- **Reproducibility Focus**: Makes the boundary between documented method and engineering judgment visible
