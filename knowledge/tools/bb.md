bb is an open-source, MIT-licensed agentic IDE built to be modified by its own users and agents. It supplies a timeline and thread-based orchestration surface for coding agents such as Claude Code, Codex, Cursor, and ACP-compatible agents, while exposing its desktop application, web application, CLI, and HTTP API as programmable surfaces. The project frames that extensibility as a path from an agent IDE to a personal software factory.

## Key Features

- Lets users run, steer, hand off, and follow agent work in persistent threads.
- Works with existing subscriptions for popular coding agents and supports ACP-compatible providers.
- Uses the same plugin and extension system for user customizations and built-in capabilities such as workflows, side chat, crons, previews, and remote access.
- Can be launched as a desktop app or through `npx bb-app`, with a local web interface.
