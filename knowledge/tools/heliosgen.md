HeliosGen (SegFault42/HeliosGen, ~3.4k stars, TypeScript) is a free, self-hosted desktop app for building AI image and video generation pipelines visually. It positions itself as an open source alternative to paid services like Higgsfield, OpenArt and Freepik, and was bookmarked via a quote tweet reacting to Higgsfield's pricey "unlimited" Seedance 2.5 offer.

## Key Features

- Infinite-canvas workflow builder that chains prompts, models, reference images and automations
- Runs locally with no account or server; generations, uploads and settings live in a local database
- Uses your own kie.ai API key for model access
- Native JSON prompt preview and an AI prompt improvement assistant
- macOS (Apple Silicon) build published; Windows and Linux builds need contributors (Tauri cannot cross-compile)
