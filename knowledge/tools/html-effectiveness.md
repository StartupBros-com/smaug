`anthropics/html-effectiveness` is a gallery of standalone HTML examples that illustrates when an agent can communicate more effectively with a self-contained interactive page than with Markdown. The examples span code review, design exploration, reports, diagrams, prototypes, and custom editing interfaces, and can be opened directly in a browser without dependencies or a build step.

## Key Features

- Categorized examples for exploration, code work, prototyping, communication, diagrams, research, and custom editing UIs.
- Self-contained `.html` files that run directly in a browser with no installation or build process.
- Demonstrations of richer agent deliverables, including slide decks, incident reports, feature-flag controls, and prompt-tuning interfaces.
