Compound Engineering is an official plugin that packages AI-assisted engineering workflows for Claude Code, Codex, Cursor, and related agent environments. It aims to make successive units of work more effective by turning planning, implementation, review, and retained learnings into reusable skills and commands.

The version highlighted here adds a `codify` command for automatically capturing learnings, an updated planning mode, and prompting patterns intended to capitalize on Opus 4.5. Its repository describes native installation paths for Claude Code, Cursor, and Codex.

## Key Features

- Provides reusable skills and commands for planning, coding, review, and related engineering workflows.
- Supports Claude Code, Codex, Cursor, and other compatible agent environments.
- Includes a `codify` workflow intended to capture project learnings automatically.
- Documents marketplace installation and migration steps for existing installations.
