Dicklesworthstone/franken_node is a pre-1.0, Rust-based JavaScript and TypeScript runtime platform built on FrankenEngine. It aims to pair Node and Bun ecosystem compatibility with extension trust controls, deterministic incident replay, and migration tooling for agent-oriented systems. At the bookmarked commit it had 28 GitHub stars.

The project is presented as the companion runtime to FrankenEngine rather than a general replacement proven in broad production use. Its stated focus is making extension-heavy JavaScript deployments more inspectable by attaching policy decisions, trust data, and replayable incident artifacts to runtime operations.

## Key Features

- Node and Bun compatibility and migration-oriented tooling
- Extension trust controls and supply-chain-oriented scanning concepts
- Deterministic replay, incident bundles, and policy counterfactuals
- Structured operational commands for audits, trust scans, and diagnostics
- Rust 2024 implementation with a pre-1.0 public interface
