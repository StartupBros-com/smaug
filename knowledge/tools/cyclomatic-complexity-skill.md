A Claude Code plugin/skill that audits code for cyclomatic complexity so agent-written ("slop") code can be refactored into something easier to read, test, and maintain. The repo README could not be extracted, so this summary rests on the tweet and the quoted tweet from @bentlegen, who showed an audit cutting a function from 91 decision paths to 12.

## Key Features

- Cyclomatic complexity audits of code
- Guides refactoring to reduce decision paths
- Packaged as a plugin for coding agents
