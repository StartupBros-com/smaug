`code-story` is an agent skill for turning a code change into a chaptered HTML explanation. Rather than presenting a reviewer with a PR diff alone, it combines selected diffs with explainers and diagrams that show how and why the change works. Its intended use is helping developers orient themselves in unfamiliar or high-consequence repositories before they decide what questions to ask and which tests to strengthen.

## Key Features

- Produces a wizard-style, chaptered HTML page for explaining a change.
- Combines individual code diffs with prose explanations and diagrams.
- Supports code-review workflows where reviewers need faster context than a raw PR provides.
- Ships as part of the `will-ness-ai/skills` collection for agent-skill harnesses.
