A collection of 45 agent skills (MIT licensed, from The Product Compass) distilled from shipping three live products. It covers deciding what to build, building it with Claude Code or Codex, having a second model review the work, and releasing it. Bookmarked because it includes the independent-review skill, which triages a reviewer model's findings by who hits the issue, how often, and whether it crosses a line such as another user's data, lost work, or an unapproved irreversible write.

## Key Features

- Six installable plugin packs (e.g. product, ai-shipping, agent-teams, agent-harness, app-stack) for Claude Code and Codex
- Works with any agent that reads SKILL.md folders (Cursor, Gemini CLI, OpenCode, Copilot)
- `/product:start-here` entry point that reports where the work stands and what is next
- Independent-review skill that triages paranoid severity labels from a second reviewer model
- Companion to the author's pm-skills repo
