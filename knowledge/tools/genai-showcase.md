MongoDB's GenAI-Showcase is a Jupyter Notebook cookbook for building generative-AI applications on MongoDB. It collects runnable agent examples across factory safety, research, investment analysis, recommendations, human resources, AWS Bedrock, and asset management, alongside RAG and model-evaluation patterns that use MongoDB's document and vector capabilities.

## Key Features

- Provides seven domain-oriented AI-agent examples with source code to run and adapt.
- Demonstrates retrieval-augmented generation workflows backed by MongoDB vector search.
- Includes patterns for model evaluation alongside agent and RAG application development.
- Positions MongoDB as a combined document database and vector store, avoiding a separate single-purpose vector database for these examples.
