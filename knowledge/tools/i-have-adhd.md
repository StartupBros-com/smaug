A skill/plugin for coding agents that stops them burying the answer: it forces action-first, numbered, concise output without preamble, recaps or closers. The repo has about 60k stars and is loosely based on The Adult ADHD Tool Kit.

## Key Features

- Ten rules: lead with the next action, number multi-step tasks, end with one concrete next step, suppress tangents, restate state each turn
- Specific time estimates, visible wins, matter-of-fact error messages, lists capped at five items
- No preamble, no recap, no closers
- Installable as a Claude Code plugin; fork and edit `skills/i-have-adhd/SKILL.md` to tune it
