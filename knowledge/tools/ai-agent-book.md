Open-source repository for the book "Deep Understanding of AI Agents: Design Principles and Engineering Practice" by Li Bojie (originally in Chinese, with community translations into about 15 languages including English). The book is built around the formula Agent = LLM + context + tools and covers 10 chapters, from fundamentals to production. It ships with 109 companion experiments and code, plus PDF and EPUB builds. The repo has roughly 57k stars.

Bookmarked because @pranavcmadhukar suggests feeding the book to Codex so it gets better at building agent harnesses, especially the chapters on context engineering and agent "eyes" (observation).

## Key Features

- 10 chapters covering agent design from principles to production
- 109 companion experiments and per-chapter code
- Downloadable PDF/EPUB, with an English edition and other community translations
- Topics include context engineering, agent memory, MCP, multi-agent systems, RAG, and RL post-training
