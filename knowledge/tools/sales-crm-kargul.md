Open-sourced Next.js 16, React 19 and Tailwind 4 CRM dashboard from Marcel (Kargul Studio), originally built in about two days with Claude and two UI-polish skills (better-ui, emil-design-eng). Ships with a CONVENTIONS.md spec describing how every component and page is built.

## Key Features

- Next.js 16 + React 19 + Tailwind CSS 4 stack
- CONVENTIONS.md as the repo-wide build spec
- SEO, robots, sitemap and llms.txt derived from a single lib/seo.ts config
