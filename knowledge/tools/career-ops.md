career-ops is an open-source, local-first AI job-search workflow for agent coding CLIs such as Claude Code, Codex, and OpenCode. It scans configured company career portals, evaluates listings with a structured A–F rubric converted to a 1.0–5.0 score, tailors a CV to promising roles, and tracks the application process.

The project packages the workflow as skills and a terminal dashboard rather than a hosted application. Its value is making the selection and preparation stages of a job search inspectable and repeatable while keeping the candidate's materials under local control.

## Key Features

- **Career-page scanning:** Searches job portals for configured employers and collects relevant listings.
- **Structured job evaluation:** Scores listings with an A–F rubric and a 1.0–5.0 scale to prioritize applications.
- **Role-specific CV tailoring:** Produces tailored application materials, including ATS-oriented PDFs through Playwright.
- **Application tracking:** Maintains a workflow for evaluating, preparing, and following individual applications.
- **Agent-CLI support:** Designed to run locally in Claude Code and other compatible coding-agent CLIs.
