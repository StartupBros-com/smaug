A Claude skill that encodes the guidance from the Refactoring UI book (Adam Wathan and Steve Schoger) so an agent can be told to fix an ugly interface and apply those design principles. Bookmarked as a ready-made design-quality skill for Claude Code. The repository README was not available when this was filed, so details come from the tweet.

## Key Features

- Packages Refactoring UI design heuristics as a drop-in skill
- Prompt Claude to improve visual hierarchy, spacing and polish of an existing UI
