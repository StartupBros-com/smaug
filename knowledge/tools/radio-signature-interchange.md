A proposal for a shared JSON file format (extension `.rsi`) for radio signatures, so one app can recognize radios another app has already learned and publish libraries other apps can read. It is a proposal for comment, not an adopted standard; the current document is RSI-1 revision 1.0.0 (15 November 2026). Fieldwatch is the first implementation, with release 1.2.0 the first conforming one.

## Key Features

- JSON file format with observation fields, rule kinds and test vectors per radio profile
- Covers frequencies beyond Wi-Fi and Bluetooth, per the Fieldwatch announcement (ESP32, SDR, external radios)
- Open participation with no fee, plus a self-declared "RSI-1 signatures supported" badge
