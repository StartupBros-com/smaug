`pi-subagents` is a Pi extension for delegating work to focused child agents, including asynchronous runs, background jobs, artifact capture, and shared-session workflows. It makes multi-agent work available through natural-language delegation rather than requiring users to define agents or invoke a separate orchestration system.

## Key Features

- Provides built-in scout, researcher, worker, reviewer, oracle, and delegate roles for common development tasks.
- Supports foreground and background subagent runs, with a fleet view and machine-readable artifacts for observing active work.
- Enables parallel review and delegation patterns while bounding cumulative child-agent spawns through configuration.
- Preserves the parent Pi session as the coordinator that assigns work and synthesizes returned results.
