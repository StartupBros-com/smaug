Fresh Start is the renamed repository object formerly used as a widely forked mirror of the Claude Code source-code leak reported on 31 March 2026. It no longer contains Anthropic source code; instead, it preserves a timeline of the disclosure, the DMCA takedown, and corrections to claims made about copies of the leak.

The repository explicitly warns against installing or running leaked copies. Those trees depend on internal packages unavailable from the public npm registry, creating an opportunity for malicious package squatters, and some circulating mirrors were reportedly trojanized.

## Key Context

- The repository says the source code was removed after Anthropic's DMCA notice.
- Its `HISTORY.md` records the leak, takedown, and subsequent misinformation corrections.
- It denies that cryptocurrency-wallet or autonomous-payment code was part of Claude Code, attributing circulated x402 code to a downstream modifier.
- It recommends using Anthropic's official Claude Code CLI rather than any leaked copy.
