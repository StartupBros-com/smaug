An MIT-licensed collection of roughly 32 marketing skills for AI coding agents (Claude Code, Codex, Cursor), published by James Dickerson (The Boring Marketer). Skills are ordered by the customer journey, and all of them read a shared set of brand files written by a `start-here` skill. User edits to those files become checks for later runs, and results feed back in. Free tools are used first, with paid ones optional. A deep local-business pack covers Google Business Profile, local SEO plans, and agency prospecting.

## Key Features

- Install with `npx skills add boringmarketer/boring-marketing-skills`, or as a Claude Code plugin via `/plugin marketplace add`
- `start-here` reads a business's site and reviews in about 3 minutes, writes the brand files, and routes to the next skill
- Get found: local-seo-plan, service-area-pages, ai-search, keyword-research, seo-content, programmatic-seo, site-audit
- Get the call: paid-ads, google-ads-tracking, ads-incrementality-check (pause test), meta-ads, speed-to-lead, creative (ads built from 336 live DTC ads)
- Retention and agency use: email-sequences, newsletter, performance-review, find-local-clients, pitch-the-fix
- Per-client folders so one agent setup can serve multiple clients
