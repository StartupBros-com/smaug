An agent skill from enesgules/dotfiles (an AI agent and terminal config repo) that measures what each GitHub Actions job bills and how long CI takes, then cuts the waste while keeping the checks that matter. @abdushbag said their team was using 43k Actions minutes a month, mostly waste, and built this skill to find it.

## Key Features

- Measures billed minutes per job and overall CI duration.
- Removes waste while preserving important checks.
- Install with `npx skills add enesgules/dotfiles --skill optimise-github-actions`.
- The same repo also has an x-post-drafting skill and shared AGENTS.md, Ghostty, fish and OBS configs.
