n8n-MCP is a Model Context Protocol server that gives AI coding assistants structured knowledge of n8n workflow nodes, their properties, available operations, official documentation, templates, and example configurations. It is intended to help Claude Code and similar clients construct and validate n8n workflows rather than infer node schemas from generic web knowledge.

The repository describes coverage across core and community nodes, including searchable integration documentation and AI-capable node variants. It supports hosted access as well as self-hosted deployments, with setup guides for several agent clients.

## Key Features

- Searchable n8n node documentation, schemas, properties, and operations
- Access to core and verified community-node metadata
- Workflow templates and ranked real-world configuration examples
- Documentation for AI-capable n8n node variants
- Setup paths for Claude Code, VS Code, Cursor, Windsurf, and Codex
- Hosted and self-hosted deployment options
