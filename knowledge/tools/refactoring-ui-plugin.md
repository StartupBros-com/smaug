`refactoring-ui-plugin` packages ten applied skills for Claude Code, Codex, and Cursor that turn the principles of the book Refactoring UI into structured AI-assisted design reviews. It is an independent implementation, not affiliated with Tailwind Labs.

Each skill targets one area (visual hierarchy, typography scale, color palette, spacing, button hierarchy, clutter, empty states, shadows, contrast, grouping). A `refactor-ui` meta-skill orchestrates a full design pass, so you can paste in a rough interface and have the agent critique and tighten it.

## Key Features

- Ten focused skills, evaluative or generative, plus a `refactor-ui` orchestrator
- Works across Claude Code, Codex, and Cursor with platform-specific usage
- Slash-command style invocation such as `/refactor-ui --design="path/to/design.md"`
