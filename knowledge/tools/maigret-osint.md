Python tool that builds a dossier on a person from a username by checking thousands of sites, with recursive search that follows discovered alternate accounts. The advanced username-OSINT option in the toolkit.

## Key Features

- Username lookup across thousands of sites
- Recursive chasing of newly found accounts
- Report generation for investigations
