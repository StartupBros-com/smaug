n8n's Self-hosted AI Starter Kit is a Docker Compose template for a local, low-code AI development environment. It combines n8n workflow automation with Ollama for running local models, Qdrant for vector search, and PostgreSQL for persistence, reducing the setup work required to prototype private AI workflows.

## Key Features

- Bundles n8n, Ollama, Qdrant, and PostgreSQL in a preconfigured Docker Compose environment.
- Includes n8n's low-code workflow platform, with more than 400 integrations and AI components.
- Supports CPU, Nvidia GPU, and AMD GPU Docker Compose profiles, with setup notes for Apple Silicon.
- Provides a sample workflow and examples such as AI agents, secure PDF summarization, Slack bots, and private document analysis.
