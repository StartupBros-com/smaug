Recon tool that gathers emails, subdomains, IPs, URLs and names for a domain from search engines, certificate transparency, DNS and other public sources. Intended for authorized assessments and company exposure checks.

## Key Features

- Passive collection from many sources
- Emails, subdomains, IPs and URLs per domain
- Runs via uv, with some sources needing no API key
