Chat On Steroids is an independent beta desktop app (Windows, macOS Apple silicon, Linux) that turns a ChatGPT conversation into Codex-style local coding: ChatGPT reads and edits real project files, runs tests, keeps terminals open and uses the desktop. It drives your ChatGPT conversation rather than invoking Codex directly, so ChatGPT Work and Codex usage limits are shared. The README carries a usage notice telling users to stay within the provider's rules. Bookmarked via a tweet arguing that goal mode plus 3 sub-agents running all day gives far more GPT 5.6 "sol-hours" on a Plus plan than Codex's weekly session allowance.

## Key Features

- Works on the real project: file edits, test runs, persistent terminals, live tool results
- Workers: split independent jobs across sub-agents that keep their context between tasks
- Long-task control: send corrections mid-run; Goal follows unfinished work; Loop continues within a brief; Compact & Resume carries history into a fresh chat
- "Steps for you": hands the human commands it must not run itself, with command, folder and expected output
- Phone notifications via ntfy or a self-created Telegram bot (status, stop/pause, deny approvals; never allow remotely)
- Stuck-chat diagnostics row showing recovery attempts; related-folders as read context only; chats organised in projects
