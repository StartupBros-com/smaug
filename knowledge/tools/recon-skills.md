`recon-skills` is an MIT-licensed catalog of focused skills for authorized external web-security assessments. It organizes reconnaissance, authentication testing, infrastructure discovery, vulnerability validation, evidence hygiene, attack-path analysis, and reporting into documented procedures with prerequisites and verification criteria.

The project is useful as a structured starting point for security practitioners who need to select investigation steps based on an observed surface rather than applying a generic checklist. It explicitly limits use to targets the operator owns or is authorized in writing to test.

## Key Features

- Covers web, API, authentication, cloud, container, and exposed-infrastructure assessment surfaces.
- Includes playbooks for reconnaissance, validation, evidence review, attack-path analysis, and reporting.
- Provides focused `SKILL.md` documents that can be searched by vulnerability class or platform.
- Includes a validation script for checking the catalog's structure and style baseline.
