Official Python library and CLI for Shodan, the search engine for internet-connected devices, enabling programmatic queries for exposed cameras, routers, servers and industrial systems. Useful for checking what your own infrastructure exposes.

## Key Features

- Search, bulk IP lookups and exploit search
- Streaming API and network alerts
- Command-line interface included
