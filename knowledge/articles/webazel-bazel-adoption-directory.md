WeBazel is an evidence-backed directory of companies whose Bazel use is supported by public citations rather than logo walls. @sluongng shared it while arguing that teams leaning heavily on coding agents should use Bazel or Buck2.

## Key Takeaways

- Lists about 181 Bazel and vendor profiles backed by about 295 public citations across 24 countries.
- Each claim is scoped and matched to a dated, reviewable source.
- Also indexes Bazel-like tools and explains its verification methodology.
- Useful as ammunition for the argument that hermetic, cached build systems suit agent-driven development at scale.
