Anthropic's data team describes how it automated 95% of business analytics queries with Claude. The accompanying approach treats self-service analytics as an agent-systems problem: the agent needs reusable skills, a sound data foundation, and evidence that its answers remain useful outside a controlled demonstration.

The post emphasizes evaluation, ablation, and online validation alongside the underlying analytics workflow. Those practices make it possible to identify which system components actually contribute to reliable answers and to check whether the resulting experience works in real use.

## Key Takeaways

- Reusable skills and accessible, well-prepared data are core building blocks for an analytics agent.
- Offline evaluations and ablations help isolate whether changes improve the system rather than merely alter it.
- Online validation is necessary to confirm that performance on analytics tasks translates to useful self-service outcomes.
