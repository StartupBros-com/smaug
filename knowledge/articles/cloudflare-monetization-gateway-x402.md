Cloudflare's Monetization Gateway is a waitlisted payment layer for charging for web pages, datasets, APIs, and MCP tools served behind Cloudflare. It is built around the x402 open protocol and settles charges in stablecoins, extending per-resource monetization to both conventional web services and agent-facing tools.

## Key Takeaways

- The gateway is intended to price access to individual web resources rather than only subscription products.
- Supported resource types include web pages, datasets, APIs, and MCP tools.
- Stablecoin settlement via x402 targets machine-readable payments that can work with agentic clients.
