GPUTable is a free, sortable table of live per-GPU hourly rental prices (on-demand, spot and reserved) across 35+ cloud providers, including AWS, Azure, CoreWeave, Lambda, Vast.ai and RunPod. Data refreshes every 5 minutes and covers H100, H200, B200, B300, A100, MI300X, RTX 4090 and more. The author built it as a side project while trying to find the cheapest place to host GPUs for a weekend idea.

## Key Takeaways

- Covers 35 GPU models and 35+ providers, with a filterable and sortable table plus plain HTML pages per GPU and per provider
- Exposes raw data as JSON (current prices and a daily price-history index), so it can be scripted against
- Ticker snapshot at capture showed Vast.ai with the lowest entry prices, and big clouds like AWS and Azure higher
