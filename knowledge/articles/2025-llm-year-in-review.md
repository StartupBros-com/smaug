Andrej Karpathy’s review argues that 2025 changed both the production training stack and the practical shape of LLM applications. He highlights reinforcement learning from verifiable rewards (RLVR), the uneven or “jagged” nature of model intelligence, vertical applications such as Cursor, local tool-using agents exemplified by Claude Code, vibe coding, and the emergence of multimodal interfaces as major shifts.

## Key Takeaways

- RLVR became a major capability-training stage, using objective, verifiable environments to support longer optimization runs and more test-time reasoning.
- Models should be understood as unlike animals: they can excel in reward-shaped domains while failing surprisingly simple tasks, which makes benchmark results less trustworthy.
- Vertical LLM applications add context engineering, multi-call orchestration, human interfaces, and adjustable autonomy around general models.
- Claude Code demonstrates a useful intermediate agent form: a local, tool-using system working inside a developer’s private environment rather than solely in cloud containers.
- Vibe coding makes software cheaper and more disposable, while multimodal systems point toward AI interfaces that communicate visually rather than principally through chat.
