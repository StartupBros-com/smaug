Stripe Directory is a public-preview discovery layer for developers and AI agents looking for businesses and services on the Stripe network. It brings together Stripe Apps, Projects.dev providers, and mpp.dev services so an integration can be found without manually searching several catalogs and websites.

Patrick Collison describes the release as an early experiment. Its premise is that a shared directory can make commercial services more discoverable to software agents as well as people, supplying a common entry point for finding businesses that can be integrated with Stripe.

## Key Takeaways

- The directory is intended as a single discovery surface for businesses and services connected to Stripe.
- It includes Stripe Apps, Projects.dev providers, and mpp.dev services rather than limiting search to one product catalog.
- The public preview explicitly supports both human developers and AI agents, signaling agent-oriented service discovery as a product use case.
