A skill page on aiforui.dev for `/learn-taste`. It gathers every design correction you make to an AI agent during a session and turns each into a strict rule with its reasoning, written into your DESIGN.md, so later agents stop repeating the same mistakes. Only the page metadata was recoverable from the fetched HTML (body was a Next.js shell), so details beyond the description are not captured.

## Key Takeaways

- Corrections made in conversation become durable, reasoned rules rather than being lost between sessions
- Output lives in DESIGN.md, which future agents read
- Most useful if you correct your agent's design output often
