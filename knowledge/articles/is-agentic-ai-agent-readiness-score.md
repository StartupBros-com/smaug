Is Agentic is a Vercel tool, backed by Ora's research, that scores how ready a website or app is for AI agents, based on what agents can discover, access, and use. You enter a URL (or run `npx is-agentic [domain]`) and every scan is run by Ora, returning evidence and recommendations for improving the site.

## Key Takeaways

- Audits with 100+ checks covering agent discoverability, access, and usability (llms.txt is among the listed keywords).
- Visualizations show agents actually using your site.
- One-click prompts generate fixes you can hand to a coding agent.
- Ships a CLI so agents can run the audit themselves; @rauchg reported looping it against Vercel's own site until it hit 100/100, and @ctatedev noted the tool is itself agentic.
