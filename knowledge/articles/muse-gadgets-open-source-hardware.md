Muse Gadgets is an open source firmware and SDK effort for building physical devices that connect to Muse. You program an off-the-shelf ESP32 board or set up a Raspberry Pi with the provided SDKs, then wire Muse to displays, buttons, sensors, actuators and other workbench parts. Nat Friedman announced it as a side project and suggests pointing a coding agent at the GitHub repo to build your own peripherals, using an API token from the site.

## Key Takeaways

- Open source ESP32 firmware plus a Linux SDK (e.g. Raspberry Pi) for Muse-connected devices
- Peripherals can be displays, buttons, sensors, and actuators
- Designed to be built with a coding agent pointed at the repo
- Requires an API token from the Muse gadgets site
