A Gas City blog post (published 2026-10-01) describing how Beads, the open-source work-tracking and memory system for coding agents, is being extended from tracking work to keeping the project knowledge agents need. Only the page metadata was extracted (the body was truncated HTML), so this summary comes from the post description and the announcing tweet: Memory Beads, a generic Bead and Link graph, the Beads Protocol (BDP, a proposed wire protocol), and versioning. The announcement notes Beads passed 1.5M downloads and a preview branch is available to try.

## Key Takeaways

- Memory Beads: versioned memories stored as beads alongside issues
- A generic Bead and Link graph generalizes beyond issue tracking
- BDP is a proposed wire protocol for Beads
- Versioning of beads is part of the extension
