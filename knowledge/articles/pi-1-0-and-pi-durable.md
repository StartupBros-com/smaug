Earendil announces Pi 1.0, a hardened, minimal, extensible agent harness, alongside Pi Durable, an experimental substrate for long-running agentic applications. Bookmarked via Dev Agrawal, who is considering rewriting his OpenCode-derived OC++ with durability as an architectural guarantee.

## Key Takeaways

- Pi 1.0 adds Codemode (native MCP plus non-LLM models), virtual-model extensions, deferred tool loading, Anthropic cache warming, mid-conversation system messages, a new TUI theme and full-screen by default
- Pi stays minimal: features are adopted only after proving themselves
- Pi Durable extends Pi's minimalism to long-running agentic apps reachable from many surfaces
