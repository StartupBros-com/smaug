Vibe Kanban’s Vibe Guide is positioned as a collection of tips and best practices for building with AI coding agents. Louis Knight-Webb introduces it as lessons accumulated after shipping more than one million lines of code with agents, framing the guide as operational experience rather than a prompt collection.

The supplied capture preserves the guide’s topic structure but not its chapter text. Its visible sections cover planning and re-planning, asynchronous work, choosing model capacity, preparing projects for QA, keeping development servers available, and adding dummy data. The current page banner also says that Vibe Kanban is sunsetting and will continue as an open-source, community-maintained project.

## Key Takeaways

- Treat planning and re-planning as core control loops for agentic development, not optional preparation before coding starts.
- Agent productivity depends on usable execution environments, including solvable dev-server workflows, dummy data, and projects that can be QA’d.
- The bookmark’s claimed scale—more than one million shipped lines—makes the guide a practitioner reference for coordinating coding agents over sustained work.
