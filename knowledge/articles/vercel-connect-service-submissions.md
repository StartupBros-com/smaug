Vercel changelog announcing that service providers can now submit their own service to Vercel Connect and be listed in its connectors directory. The submission flow has you describe the service, configure OAuth or API key auth, verify it with a real token call, and submit for review. Guillermo Rauch pitched it as a way to reach 20M+ developers and the agents they ship, arguing that connecting to external services is the remaining hard part of building now that code is cheap, and that Connect avoids handing static credentials to every agent or app.

Note: only the page metadata was captured (the body text was truncated), so details come from the meta description and the tweet.

## Key Takeaways

- Services can self-submit to the Vercel Connect connectors directory
- Submission covers service description, OAuth or API key auth, a verified real token call, then review
- Pitch: Connect replaces per-agent static credentials, which are both a DX burden and a security liability
