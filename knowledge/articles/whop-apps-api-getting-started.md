Whop’s Apps API getting-started page accompanies an API and SDK launch for builders in its app ecosystem. The preserved page response does not contain the guide’s readable body, but the quoted launch announcement identifies more than 80 endpoints, official TypeScript, Python, and Ruby SDKs, and MCP support. Vas frames the new Whop app store as an early distribution opportunity whose apps can also be deployed outside Whop rather than being platform-exclusive.

## Key Takeaways

- The launch advertises an Apps API with more than 80 endpoints.
- Whop provides SDKs for TypeScript, Python, and Ruby.
- The API includes MCP support, making it accessible to compatible AI-agent workflows.
- The bookmark’s commentary positions the app store as a first-mover channel, although its growth projections are the author’s speculation rather than product documentation.
