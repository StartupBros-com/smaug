The first public agent skill published by Vercel CEO Guillermo Rauch, listed on skills.sh. The ui-recording-timeline skill turns a screen recording of a UI (page load, navigation, redirect/auth flow, app startup) into an interactive paint timeline page, with a full-window video and frame-level timeline. Only the page description was retrievable; the rest of the page content was truncated.
