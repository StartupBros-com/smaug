Getting-started page for building MCP Apps that run inside Claude. The fetched content was raw HTML with only the page description readable: it covers what an MCP App can do in Claude (side panel, app tools, embedded websites), an example to try, and building your own with the SDK. The tweet announces that Claude now supports more of the MCP Apps extension, including app tools and embedded sites, so a full app can run inside Claude.

## Key Takeaways

- Claude now supports app tools and embedded sites from the MCP Apps extension
- Apps can render in a side panel next to the conversation
- Related launch: interactive connectors let you open the full version of Adobe, Atlassian, and Box tools beside the chat (web and desktop rollout)
- Docs point to an example app and the SDK to build your own
