auto-harness is an open-source library for self-improving agentic systems. It is designed to identify an agent's failures, convert those failures into automated evaluations, and use the resulting feedback loop to guide fixes during extended runs.

## Key Takeaways

- The project packages a self-improvement loop around failure discovery, evaluation creation, and agent fixes.
- Its auto-evals make agent behavior testable rather than relying solely on anecdotal observations.
- The intended workflow lets developers connect an agent and run iterative improvement over a long unattended session.
