Vibhor Chhabra, Product Lead for Ecosystem at OpenAI, recaps the ecosystem announcements from DevDay and the partner collaborations behind them (Adobe, Atlassian, Canva, Figma, Instacart, MagicPath, Shopify, Superpower, tldraw). The framing is that a conversation is often only the start of a task, and plugins let ChatGPT hand off to interactive tools where users can keep refining the result.

## Key Takeaways

- Plugin Extensions bring interactive UI into ChatGPT: Adobe image edits with hands-on controls, a shared tldraw canvas for user and agent, and editable MagicPath prototypes inside the conversation.
- A plugin can package skills, an MCP server, or both, covering reusable workflow knowledge, live data access, and actions. A Plugin Creator and automated submission checks with clearer feedback were introduced.
- Plugin discovery, ranking and recommendations are being improved, both in the directory and inline in conversations.
- MCP Events lets users ask ChatGPT to watch for supported events (a new message, a document comment) and respond when they arrive, extending tools beyond a single exchange.
- ChatGPT Sites can host MCP servers, including plugin extensions, so a builder can deploy a server, turn it into a plugin, and install it across platforms.
