Peter Yang interviews product-discovery coach Teresa Torres about using Claude Code and an Obsidian vault as a personal operating system. Torres treats Claude as a persistent collaborator across task management, research, writing, and software work, while keeping the system legible through small Markdown files, scoped instructions, and human review.

## Key Takeaways

- A `/today` command can scan Markdown task files, check connected systems such as Trello, and generate a daily view containing overdue work, current tasks, and research to review.
- Torres separates durable context into global preferences, project-specific rules, and small reference files that Claude loads only when relevant, avoiding an overloaded default context window.
- Rather than documenting everything at once, she creates and maintains context files incrementally whenever repeated explanation would otherwise be necessary.
- For long-running work, shared process notes preserve decisions and session history before a context reset, giving the next conversation an explicit recovery point.
- Claude acts as a researcher, editor, and thought partner for writing, while Torres keeps authorship and judgment by drafting in her own voice and approving proposed edits.
